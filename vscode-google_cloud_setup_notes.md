# VSCode & Google Cloud remote development set up

Notes for set up of Visual Studio Code for remote development on Google Cloud compute instance VM. Host OS is Ubuntu 24.04.

## 1. Google Cloud Compute Engine

To access Google machines for remote development via SSH we need to set up authentication with Google Cloud CLI and then add the machine as a remote in VS Code.

### 1.1. Install Google Cloud CLI

**Detailed install instructions**: [Install the Google Cloud CLI](https://docs.cloud.google.com/sdk/docs/install-sdk#deb)

Google Cloud CLI is installed via apt, after adding the Google Cloud package source.

#### 1.1.1. Install setup dependencies

Need a few things first:

```text
sudo apt install apt-transport-https ca-certificates gnupg curl
```

#### 1.1.2. Add the package source

Import the Google Cloud public key:

```text
curl https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo gpg --dearmor -o /usr/share/keyrings/cloud.google.gpg
```

Add the source:

```text
echo "deb [signed-by=/usr/share/keyrings/cloud.google.gpg] https://packages.cloud.google.com/apt cloud-sdk main" | sudo tee -a /etc/apt/sources.list.d/google-cloud-sdk.list
```

Check the result - there should not be duplicate entries for the `cloud-sdk` repo in `/etc/apt/sources.list.d/google-cloud-sdk.list`. Verify with:

```text
$ cat /etc/apt/sources.list.d/google-cloud-sdk.list

deb [signed-by=/usr/share/keyrings/cloud.google.gpg] https://packages.cloud.google.com/apt cloud-sdk main
```

#### 1.1.3. Install

Update and install the CLI with apt like any other package:

```text
sudo apt update
sudo apt install google-cloud-cli
```

Verify the install with:

```text
$ gcloud --version

Google Cloud SDK 550.0.0
alpha 2025.12.12
beta 2025.12.12
bq 2.1.26
bundled-python3-unix 3.13.10
core 2025.12.12
gcloud-crc32c 1.0.0
gsutil 5.35
```

Run `gcloud init` and follow the prompts. Set default region to `us-central1-a`.

### 1.3. Compute Engine remote access

#### 1.3.1. SSH

Connect via command line with `gcloud`:

```bash
gcloud compute ssh --zone "us-central1-c" "vostok" --project "ask-agatha"
```

The first time this command is run, `gcloud` will set up a key pair and then log in. Exit the VM instance and run the following on the host machine:

```bash
gcloud compute config-ssh
```

This will add an alias to `.ssh/config`:

```text
# Google Compute Engine Section
#
# The following has been auto-generated by "gcloud compute config-ssh"
# to make accessing your Google Compute Engine virtual machines easier.
#
# To remove this blob, run:
#
#   gcloud compute config-ssh --remove
#
# You can also manually remove this blob by deleting everything from
# here until the comment that contains the string "End of Google Compute
# Engine Section".
#
# You should not hand-edit this section, unless you are deleting it.
#
Host vostok.us-central1-c.ask-agatha
    HostName 34.133.199.134
    IdentityFile /home/siderealyear/.ssh/google_compute_engine
    UserKnownHostsFile=/home/siderealyear/.ssh/google_compute_known_hosts
    HostKeyAlias=compute.4324095870367587371
    IdentitiesOnly=yes
    CheckHostIP=no

# End of Google Compute Engine Section
```

Though the boilerplate says not to edit the alias stanza, changing the hostname seems to work fine. You should now be able to access the Google machine via ssh: 

```text
ssh vostok.us-central1-c.ask-agatha
```

At this point, you have full control of the system and are the sole tenant, so feel free to mess around and install whatever you want (no crypto mining or legally questionable content though please, big-brother-google will know...). It's a VM, so if you break it - just let me know - I can reset it in two clicks. It's ephemeral and you should treat it as such. Commit and push or otherwise exfiltrate any assets regularly. If it crashes or restarts for any reason, don't trust that your files will still be there (the system configuration will survive across boots). 

### 1.4. Environment setup

First, update and upgrade with apt: `sudo apt update && sudo apt upgrade`.

#### 1.4.1. Install git

```text
sudo apt install git
```

Add a your SSH key to GitHub. First generate a key:

```text
ssh-keygen -t rsa
```

Then copy the contents of `~/.ssh/id_rsa.pub`. Next go to GitHub and add it as a new SSH key. Profile badge upper right -> settings -> SSH and GPG keys (under 'Access' on the left)  -> New SSH key (green button, top right). Give it a name you will remember, and paste the public key in. Add and you're done.

#### 1.4.2. Install Docker Engine

**Detailed install instructions**: [Install Docker Engine on Ubuntu](https://docs.docker.com/engine/install/ubuntu)

Docker Engine is installed via the Docker apt repository. First add the GPG key:

```text
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

Then add the source repository:

```text
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/debian
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF
```

Update and install:

```text
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

## 2. VS Code

### 2.1. Install VS Code locally

**Detailed install instructions**: [Visual Studio Code on Linux](https://code.visualstudio.com/docs/setup/linux)

VS Code is installed via the .deb, which will add the apt repository. Future updates/package management can then be handled via apt.

1. Download the Debian/Ubuntu .deb file from the VScode [downloads page](https://code.visualstudio.com/Download)
2. Install the .deb file with apt: `sudo apt install code_XXXX_amd64.deb`

Replace XXXX with the current version string. After installation, you do not need to keep the .deb file.

### 2.2. Connect to Google machine

Not much to do here - launch VS Code and go to 'Remote Explorer' in the activity bar (at the left) and select 'Remotes (Tunnels/SSH). You should see the Google machine listed by the hostname assigned in ~/.ssh/config. Click 'Connect in Current Window' and you should be good to go!

## 3. Set up project from GitHub

### 3.1. Clone

Clone the GitHub repo using the ssh url:

```text
git clone git@github.com:gperdrizet/hill_climber.git
```

### 3.2. Start dev environment

Open the new project directory via VS Code. Go to 'File -> Open Folder' while connected to the Google machine. Select the directory you just cloned.

Once the directory is loaded, open the command pallet and find 'Dev: open folder in container'. Once the container builds, you should be all set!
